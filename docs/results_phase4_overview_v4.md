# Phase 4 absolute scores (v4)

Generated by `PFE_DATASET=v4 python -m src.analysis.phase4_overview`. Do not edit by hand.

Scores are medians across core wells for simulation using the `all` scoring variant. The well count is the number of core wells with a drought RMSE. A dash marks an unavailable value. A run is pending when its per-well metrics file is absent.

R1 uses the full training period. The `_lwo` rows pool predictions from the five leave-wells-out folds. The `_f25` and `_f50` rows use the most recent 25% and 50% of the training period. The `_refit` rows fit on training and validation, so any validation scores for those rows are in-sample. [Phase 4 run plan](phase4_runs.md)
