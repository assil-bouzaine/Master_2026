Description

  • Country-agnostic Earth-observation module of the LULC-Water network. Starts empty at 0.10.0; satellite spectral-index observations and probable-irrigation terms (CQ15) will be added in a subsequent step.

  • Module d'observation de la Terre indépendant des pays du réseau LULC-Water. Initialement vide en version 0.10.0 ; les observations d'indices spectraux satellitaires et les termes d'irrigation probable (CQ15) seront ajoutés dans une étape ultérieure.

  • Values of lulcw:IrrigationOutcome (CQ15).

  • Values of lulcw:RuleValidity (CQ15).
