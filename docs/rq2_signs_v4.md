# RQ2: wrong-signed response gains in v4

**descriptive, on saved v4 parameters**

Generated by `PFE_DATASET=v4 python -m src.analysis.rq2_signs`. No model is fitted. This checks the plausibility half of analysis-plan-v2 §10 RQ2; the separate accuracy contrasts are in [results_arms_v4.md](results_arms_v4.md).

The denominator is all 33 core wells × every saved start, including wells without an active input edge. These are parameter signs; a wrong gain on a zero input does not imply a wrong contribution. R2 reads every fold but selects each well only in its held-out fold, as in the saved LWO predictions. It does not count the same well again in folds where it trained.

Expected signs: recharge ≥ 0; attributed and unattributed pumping ≤ 0; river_c ≥ 0 only at wells where all river edges in arm D's export are constrained. Plain river and canal have **no rule**. The CSV merges river_c into `gain_river`; `river_constrained` selects its rows. Each file's mask is checked against the export and its saved config.

Frozen export release: `2026-11-21T23:00:58+00:00`. Constrained river wells: `10906X0039/C2-1`, `10962X0074/PZ`, `10962X0075/PZ`. Core subset: `10906X0039/C2-1`, `10962X0074/PZ`.

Each slot cell gives **share wrong over well × start / share of wells with a strict majority of starts wrong / median |wrong gain|**. Exactly zero is not wrong; a 50% tie is not a majority. The median is in metres per unit model stress, from `parameters_physical`; — means no wrong gains. Model stresses use rain/10 and ETP/10 for linear recharge, pump_gw/100, pump_un/100, river/1 and canal/10 (the saved config's scaling). Magnitudes across different slots are not directly comparable.
