# LULC-Water ontology network

Permanent identifiers for the LULC-Water network of ontologies (land use, land cover and
groundwater; SAVE Water project, PRIMA), developed for a Master's thesis at ISAMM, Université de la
Manouba.

- `https://w3id.org/lulcw` and `https://w3id.org/lulcw#<term>`: the bridging module
- `https://w3id.org/lulcw/meta`: the network (imports every module)
- `https://w3id.org/lulcw/alignments/<name>`, `https://w3id.org/lulcw/imports/<name>`: its modules
- `https://w3id.org/lulcw/shapes`, `https://w3id.org/lulcw/rules`: SHACL shapes and rules
