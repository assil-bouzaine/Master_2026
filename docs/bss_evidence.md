### Plain verdict

- **Does `bss_record` reach `PRECISION_PROBABLE` (0.80) with at least `MIN_EVAL` (10) points among irrigation boreholes (`MIN_USE_EVAL` = 5)?** **No.**
- **Zero** (`0 < 5`) irrigation boreholes exist in the 130-borehole recorded evaluation set (all 130 evaluated boreholes are drinking water [114] or industry [16]). By task 12.3's rule, no measured precision can promote an irrigation heuristic to `probable` without irrigation validation points.
- **Direct BSS code join** matches ADES verbatim (group and exact precision 0.969 after the depth check, 1.000 raw), but reaches only **8** of 1,485 plain irrigation boreholes (**2.61 Mm³**, **1.62 %** of plain irrigation volume) because 99.5 % of plain BNPE irrigation boreholes carry no BSS code.
- **Location matching** reaches **8.7–26.6 %** of plain irrigation volume across D = 50–500 m (**14.11–42.92 Mm³** including the 8 direct-join points), **but** fails precision on two counts: (i) on known-code points, the nearest BSS water point is the same borehole only **13.3–39.4 %** of the time (largely because 86 % of known-code BSS water points are blurred to commune centroids), and (ii) on the 130 recorded boreholes, location-matched `bss_record` achieves group precision of only **0.333–0.800** (exact **0.333–0.750**), below `0.80` at every D.
- **Bottom line:** BRGM's open BSS layers do **not** unlock `probable` irrigation links for the main policy. Direct BSS code joins add 24 unrecorded BNPE points (16 distinct boreholes, **14.73 Mm³** total; only **2.61 Mm³** irrigation) with ADES-identical records (requiring the same 50 m depth check—note drinking-water borehole `10972X0133/LATOUR`, 165 m deep in `718BP04`). Location-matched BSS links, if ever added, must stay `possible` (sensitivity run only).
