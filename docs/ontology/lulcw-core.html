Description

  • Country-agnostic core vocabulary of the LULC-Water ontology network: provenance (data releases, source records, derivation rules), qualified assertions, shared answer-contract and evidence schemes, and generic register-code and measurement properties.

  • Vocabulaire noyau indépendant des pays du réseau d'ontologies LULC-Water : provenance (versions de jeux de données, enregistrements sources, règles de dérivation), assertions qualifiées, schémas partagés du contrat de réponse et des preuves, et propriétés génériques de code de registre et de mesure.

  • Values of lulcw:AnswerStatus (docs/competency_questions.md §2).

  • Values of lulcw:AssessmentStatus.

  • Values of lulcw:AttributionRole.

  • Values of lulcw:ConfidenceLevel (src/kg/pump_attribution.py).

  • Values of lulcw:EvidenceKind.

  • Values of lulcw:Resolution.
